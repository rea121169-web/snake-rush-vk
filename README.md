# Snake Rush — VK Mini App

Production-версия HTML5-игры Snake Rush для запуска в VK Mini Apps и как самостоятельная статическая страница.

- 30 уровней и 5 миров
- бесконечный режим, скины, магазин и достижения
- клавиатура, экранные кнопки и свайпы
- локальные сохранения через `localStorage`
- VK Bridge 3.0.2 (`VKWebAppInit`)
- относительные пути, совместимые с GitHub Pages

## Запуск локально

Откройте папку через любой статический HTTP-сервер, например:

```powershell
python -m http.server 8080
```

Затем перейдите на `http://localhost:8080/`.

## Публикация

GitHub Pages публикует содержимое ветки `main` из корня репозитория.
